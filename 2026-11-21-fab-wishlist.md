# What to download from Fab (Quixel Megascans), in order

Aarush: these are the exact names as Fab lists them under the two sellers you linked. Search each name on Fab, add it, download.

**How to download each one**
- Format: **glTF** (not Unreal, not FBX).
- Quality: the **smallest** tier offered ("Low" or 2K textures). I shrink everything anyway; big files only slow the upload.
- Put them all in one zip (or several) and upload here. Keep Fab's folder names so I can tell them apart.

## Not worth downloading
The big tree sets (Megaplants: European Hornbeam, Oak, Beech, Spruce...) and the Nordic rocks and cliffs. They are the wrong forest, and each is hundreds of MB.

## Three things you should know
- **None of these is from the Amazon.** Fab has no Mamirauá plants. These are stand-ins (kapok and banyan bark, generic tropical palms and ferns). Every one goes on the list for the reserve's reader to check (`UNSOURCED.md`).
- **The repository must be private once these files are in it.** Megascans may be used inside a game, but the raw files may not be handed out. A public repository hands them out. The public link itself is fine, because it only carries the shrunk, baked versions.
- **The download gets bigger.** With these in, the link will be roughly 15 to 40 MB instead of under 3 MB, and the "one HTML file" will be that size too. I will keep a "no downloaded assets" level so it still runs light on weak machines.
