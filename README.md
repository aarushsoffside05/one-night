# One Night Through the Forest

A single-player browser game: a boy travels one night through a real flooded-forest reserve in the Amazon (Mamirauá, Amazonas, Brazil) with a fishing family. The family is made up. Internal build: not to be shown to children or published as finished until a reader from the reserve's own communities has seen it.

- `PROGRESS.md`: where the work stands and how to run everything.
- `DECISIONS.md`: every call made without asking, and Aarush's decisions.
- `UNSOURCED.md`: everything shown or said that is not on the brief's list of facts.
- `2026-11-21-fab-wishlist.md`: the Fab download list.

Run: `npm ci`, `npm run dev`. Build: `npm run build` (makes `dist/` for the link and `dist/one-night.html`, the single file).

Third-party material: three.js, React, React Three Fiber, Vite (MIT). People: Microsoft Rocketbox avatars (MIT). Surfaces and plants: Quixel Megascans via Fab (Fab standard licence; raw files are not in this repository and must not be redistributed). The repository should be private.
